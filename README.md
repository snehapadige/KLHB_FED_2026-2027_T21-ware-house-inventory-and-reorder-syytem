## Abstract 
 
The **Warehouse Inventory and Reorder System** is a Java-based application designed to efficiently manage and monitor inventory in a warehouse. The system helps maintain product details, track stock quantities, manage storage locations, and monitor the availability of products. It stores important information such as product ID, product name, quantity available, storage location, and reorder point. When new stock is received, the inventory quantity is updated and the products can be assigned to suitable storage bins. When an order is processed, the required products are picked from the available stock and the inventory quantity is reduced accordingly. The system continuously checks the available stock against the reorder point. If the quantity reaches or falls below the reorder point, the system identifies the product for reordering. This helps prevent stock shortages, improves inventory accuracy, and makes warehouse operations more organized. The project demonstrates the practical use of Java programming concepts such as classes, objects, methods, conditional statements, loops, and collections. Overall, the system provides a simple and efficient solution for warehouse inventory management and timely stock replenishment.

## Setup Instructions 
 
1. Install the Java Development Kit (JDK) on the system.
2. Verify that Java is properly installed by checking the Java version.
3. Clone or download the project repository from GitHub.
4. Navigate to the project directory.
5. Open the `src/` folder and locate the main Java source file.
6. Compile the Java source code using the Java compiler.
 
## Execution Instructions 
 
1. Open the project folder in a terminal or command prompt.
2. Navigate to the `src/` directory.
3. Compile the Java program using:

javac WarehouseInventoryReorderSystem.java
